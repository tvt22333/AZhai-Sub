AZhai Sub

新一代二级域名管理器

«从快乐 DNS 开始，到 AZhai Sub»

项目起因

我最早接触二级域名的时候，使用的是「快乐 DNS」，那也是我域名启蒙的开始。

在使用的过程中，我逐渐发现它还有一些地方可以改进，于是开始尝试重新设计和重构。

在重构代码的同时，我也参考了一些国内网站的首页设计与交互方式，希望做出一个更加完整、现代的二级域名管理系统。

于是，AZhai Sub 就这样诞生了。

它不仅仅是一个二级域名申请系统，更希望成为一个简单、易用、功能完整的二级域名管理平台。

项目介绍

AZhai Sub 是一个新一代二级域名管理器，定位类似于 "us.kg" 等二级域名服务。

无需搭建 NS 服务器，只需要拥有一个域名即可开始使用。

例如你拥有：

xxx.com

用户申请：

you.xxx.com

那么：

*.you.xxx.com

都可以由用户进行管理。

DNS 记录类型

目前支持以下 DNS 解析类型：

- A
- AAAA
- CNAME
- TXT

«注意：TXT 根域名验证需要用户先提交 TXT 验证申请，管理员审核通过后，再由管理员手动添加 TXT 记录。»

DNS 服务商

目前支持：

- Cloudflare
- 阿里云 DNS

后续版本计划接入：

- 华为云
- 腾讯云
- 西部数码
- 其他 DNS 服务商

快速开始

1. 上传项目

将项目上传并解压到网站目录。

2. 导入数据库

创建数据库后，将项目中的：

database.sql

导入数据库。

3. 修改配置

编辑：

config.php

填写数据库连接信息。

如果需要使用「阿宅登录」，也可以在这里配置 OAuth 信息。

4. 登录后台

默认后台地址：

https://你的域名/admin

默认管理员账号：

用户名：azhai
密码：azhai123

首次登录后建议立即修改默认密码。

阿宅登录

AZhai Sub 支持接入「阿宅登录」。

只需要前往：

"oauth.azhai.de" (https://reference-url-citation.invalid/1)

申请 OAuth 密钥，然后将密钥填写到 "config.php" 中。

配置完成后，注册一个阿宅账号，即可使用同一个账号登录所有接入阿宅 OAuth 的项目。

在线升级

AZhai Sub 内置在线升级功能。

后续版本更新将通过后台的：

系统更新

进行升级。

无需重新下载、上传和覆盖文件，进入后台检查更新即可升级到最新版本。

升级快人一步。

技术栈

- PHP 8
- MySQL 8

已知问题

前台主页显示错误

如果遇到前台主页显示异常，请进入：

你的网站/admin

然后点击：

系统更新 → 检查更新 → 更新

通过在线更新即可修复该问题。

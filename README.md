# AZhai Sub

**新一代的二级域名管理器**

> 从快乐 DNS 开始，到 AZhai Sub

## 项目起因

我最早的二级域名是快乐 DNS，那也是我域名启蒙的开始。

后来我觉得还缺少了点什么，于是开始重构代码，同时参考了一些国内网站的首页设计与交互方式。

于是，**AZhai Sub** 就这样出现了。

## 项目介绍

AZhai Sub 是一个新一代的二级域名管理器，堪比 `us.kg`。

**无需 NS 服务器，只需要申请二级域名即可使用。**

例如你拥有：

`xxx.com`

用户申请：

`you.xxx.com`

那么 `*.you.xxx.com` 下的域名都可以进行管理。

## 功能特性

- 二级域名申请与管理
- 域名申请审核
- 自定义二级域名
- DNS 解析管理
- SSL 证书申请
- 域名启用、暂停与恢复
- DNS 记录自动同步
- 在线系统更新
- 管理员后台
- 用户管理
- 域名管理
- DNS 服务商管理
- 操作日志
- 阿宅 OAuth 登录
- 多 DNS 服务商支持

## DNS 解析

目前支持以下 DNS 记录类型：

- A
- AAAA
- CNAME
- TXT

> **注意：** TXT 根域名验证需要用户申请 TXT 验证，管理员审核通过后，再由管理员手动添加 TXT 记录。

## DNS 服务商

目前支持：

- Cloudflare
- 阿里云 DNS
- 华为云 DNS
- 腾讯云 DNS
- 西部数码 DNS

后续还会根据实际需求继续接入更多 DNS 服务商。

## SSL 证书

AZhai Sub 支持 SSL 证书申请功能。

用户可以针对自己的二级域名申请 SSL 证书，让分配的二级域名能够更加方便地使用 HTTPS。

## 如何使用

### 1. 上传项目

将项目上传到网站目录并解压。

### 2. 导入数据库

创建数据库后，将项目中的 `database.sql` 导入数据库。

### 3. 修改配置

编辑 `config.php`，填写数据库连接信息。

如果需要使用「阿宅登录」，也可以在这里配置 OAuth 信息。

### 4. 登录后台

后台地址：

`https://你的域名/admin`

默认管理员账号：

- 用户名：`azhai`
- 密码：`azhai123`

> **首次登录后建议立即修改默认密码。**

## 阿宅登录

AZhai Sub 支持接入「阿宅登录」。

前往：

https://oauth.azhai.de

申请 OAuth 密钥，然后将密钥填写到 `config.php` 中。

配置完成后，注册一个阿宅账号，即可使用同一个账号登录所有接入阿宅 OAuth 的项目。

## 在线升级

AZhai Sub 内置在线升级功能。

后续版本更新都可以通过后台的：

`系统更新`

进行升级。

进入后台后点击检查更新，即可获取并安装最新版本。

无需重新下载、上传和覆盖文件。

**升级快人一步。**

## 项目愿景

AZhai Sub 从一个简单的二级域名项目开始。

从最初的快乐 DNS，到后来的代码重构，再到现在的 AZhai Sub，我希望它能够逐渐成为一个更加完善的二级域名管理平台。

从最初只支持少量 DNS 服务商，到现在支持 Cloudflare、阿里云、华为云、腾讯云、西部数码，再到 SSL 证书申请等功能，AZhai Sub 也在不断完善。

未来还会继续增加更多实用功能，让二级域名的申请、解析、管理和 HTTPS 配置变得更加简单。

**AZhai Sub —— 让二级域名管理变得简单。**
